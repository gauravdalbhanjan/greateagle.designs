CHASHMA

Keyboard shortcut that magnifies the search —
so you always know exactly where you are.

Download CHASHMA — it's free How to install
One keystroke, zero hunting
Press Ctrl + Shift + S (or ⌘ + Shift + S on Mac) and the active search field lights up instantly — wherever you are on the page.
Tab through every search
Multiple search inputs on the page? Tab cycles through all of them. A counter badge shows exactly which one you're on — 2 / 5, no guessing.
Always fits the field
The overlay stretches to match the input exactly — 8 pt padding on each side horizontally, flexible height. Repositions instantly on scroll or resize.
Zero data, zero tracking
Uses only the activeTab permission — the minimum Chrome allows. No analytics, no network requests, nothing stored. It runs and disappears.

How to install

1
Download & unzip
Click Download CHASHMA above, then unzip the file — you'll get a CHASHMA folder.
2
Open Chrome Extensions
Navigate to chrome://extensions in your Chrome address bar.
3
Enable Developer mode
Toggle Developer mode on (top-right corner of the Extensions page).
4
Load the extension
Click Load unpacked and select the unzipped CHASHMA folder. That's the one-time setup — Chrome doesn't allow direct one-click installs outside its Web Store, so this is the fastest route.
5
Try it
Go to any website, press Ctrl + Shift + S (or ⌘ + Shift + S) — the search field will light up. Done.

Privacy — the short version

CHASHMA uses only the activeTab permission — it activates only on the tab you're on, only when you press the shortcut. It collects no data, makes no network requests, and stores nothing. When you dismiss the overlay it leaves zero trace.
